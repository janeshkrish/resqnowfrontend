# ResQNow fonts

These are the same four font families, axes and icon subset previously loaded from Google Fonts. Unmodified WOFF2 assets are served locally so packaged Android builds and offline/cold-start pages do not depend on the font CDN.

`manifest.json` records the source URLs, SHA-256 hashes and sizes. Inter, Manrope and Plus Jakarta Sans retain their included SIL Open Font Licenses; Material Symbols retains Google's Apache 2.0 license. Keep these notices with redistributed assets. This changes delivery, not the app's chosen typography or icon names.
